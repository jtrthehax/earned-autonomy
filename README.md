## What This Paper Argues

Autonomous AI systems currently conflate values alignment with execution governance. Constitutional AI solves *intent*, but not *action*. Earned Autonomy introduces the missing execution‑gate architecture — a structural separation between assessment, proposal, and execution — and a tiered, per‑domain trust model that prevents hallucinations from becoming real‑world actions. The Anthropic autonomous‑agent incident of 2026 confirmed the first prediction of this framework.

## Key Contributions

- Formal definition of the **execution gate** as a structural requirement for autonomous AI  
- A four‑tier autonomy model (T0–T3) with **per‑domain trust** and **bounded blast radius**  
- Demonstration of the **hallucination‑execution connection** as the core safety gap  
- Timestamped predictions (P1–P5) with confirmation windows and one confirmed incident  
- A causal chain linking hiring filters → team substrate → architecture gap → real‑world failure
